# Technology Stack

## Core
- **Framework**: Next.js 16.2.6 (App Router)
- **Language**: TypeScript (v5)
- **Runtime Environment**: Node.js (v20+)

## Styling & UI
- **CSS**: Vanilla CSS (`theme.css`, `motion.css`) + Tailwind CSS v4 (`@tailwindcss/postcss`)
- **Typography**: Geist font family (`geist`)
- **Icons**: Lucide React (`lucide-react`), Radix Icons (`@radix-ui/react-icons`), React Icons (`react-icons`)
- **Animation**: Framer Motion (`framer-motion`), Lenis smooth scrolling (`lenis`)

## 3D Assets
- **Engine**: Spline (`@splinetool/react-spline`, `@splinetool/runtime`)

## State & Data Management
- **State**: Zustand (`zustand`)
- **Forms & Validation**: React Hook Form (`react-hook-form`), Zod (`zod`), Hookform Resolvers (`@hookform/resolvers`)
- **Charts**: Recharts (`recharts`)

## Backend & Authentication
- **Auth**: NextAuth.js (`next-auth`) with Prisma Adapter (`@auth/prisma-adapter`)
- **Database**: Prisma ORM (`@prisma/client`, `prisma`), Supabase SSR (`@supabase/ssr`)
- **Security**: Bcrypt.js (`bcryptjs`)
